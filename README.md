# Tideology's Codebook

The ICPC team reference document of Tideology from National Taiwan University (NTU).

It is built on KACTL, KTH's ICPC reference document, and customized with the algorithms and templates our team actually uses in contests.

See kactl.pdf for the printable version, and content/ for the source code.
